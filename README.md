# Replication package (revised)

**How connected is green finance? State dependence and research design in spillover estimates: a meta-analysis**

## Contents
| Path | Description |
|---|---|
| `data/meta_estimates_203.csv` | 203 coded connectedness estimates from 65 studies (A* census plus purposive sample of A studies); source table/section of every value, value source, moderators, baseline flag. Mensi et al. (2025) added in this revision (3 rows; values from its Table 2; T derived from sample period at 252 days/year; net role not coded). |
| `data/meta_screening_log.csv` | All 81 studies screened, with inclusion status and exclusion reasons. |
| `data/review_sample_257.csv` | The 257 review studies with cluster and ABDC rating. |
| `data/bibliometric_corpus_745_identifiers.csv` | Scopus EIDs/DOIs of the 745-document corpus (full records not redistributable). |
| `code/meta_analysis.py` | Pooled effects (REML + Hartung-Knapp; DL and Paule-Mandel as sensitivity), median/tail pooling, subgroup and multivariable moderators, publication-bias tests, Table 6 columns 1-3, robustness, lower-vs-upper tail. Writes `output/meta_results.json`. |
| `code/extra_analysis.py` | Figures 4-10 and C.1-C.3 and supporting tables. Run after `meta_analysis.py`. |
| `figures/`, `tables/` | Outputs of the scripts. |

## Running
```
pip install pandas numpy scipy statsmodels matplotlib
python code/meta_analysis.py
python code/extra_analysis.py
```
The wild cluster bootstrap uses a fixed seed (1).

## Changes from the first version
1. Pooling uses REML tau^2 and Hartung-Knapp intervals (DL gave tau^2 about half as large).
2. Median/tail pooled estimates use the mean of each study's estimates in that state (the first version depended on row order).
3. Adjusted TCI capped at 100.
4. "Excluding Dai et al. (2023)" no longer also drops Dai et al. (2024) (code bug).
5. Trim-and-fill uses the standard fixed-effect centre; the random-effects-centred variant is reported as unstable.
6. Mensi et al. (2025) added.
7. Table 3, Table 4 median/tail rows and Table 6 columns (1)-(3) are now generated by the code.

## Notes
Connectedness indices are reported without standard errors; sampling variances are approximated as v = 1/[T p (1-p)] on the logit scale, with T/10 and T/100 sensitivity analyses.
